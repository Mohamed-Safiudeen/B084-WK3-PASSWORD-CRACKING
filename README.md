## Project Modules

### W3-PM1: Password Cracking with John the Ripper (JTR)

**Objective:**  
To understand password cracking using John the Ripper (JTR) and its graphical interface, Johnny, by recovering passwords from protected PDF files.

**Tools Used:**
- John the Ripper (JTR)
- Johnny GUI
- Online PDF Hash Extractor
- Notepad

**Procedure:**
1. Downloaded and configured John the Ripper and Johnny.
2. Selected the password-protected PDF files.
3. Extracted the PDF hashes using the online PDF Hash Extractor.
4. Saved the extracted hashes in a text file.
5. Loaded the hash file into Johnny.
6. Started the password-cracking process.
7. Used the recovered passwords to open the protected PDF files.

**Results:**

| PDF File | Recovered Password |
|---|---|
| My Locked PDF 1 | `good-luck` |
| My Locked PDF 2 | `password1` |
| My Locked PDF 3 | `1qaz2wsx` |
